# Sprawa rodowodu Volt-R

Gra na telefon do wykładu 6 „Izolacja procesów” z kursu *Bezpieczeństwo w systemach operacyjnych i programowaniu systemów*.

Emerytowany policjant Stanisław Głąb, baron de Thunder-ten-Tronkh i owczarek Volt-R tropią włamywaczy Nieszczególnego i Kadrylla — za pomocą `chroot`, przestrzeni nazw, grup kontrolnych, seccomp, piaskownic oraz kontenerów i maszyn wirtualnych. Sześć misji, ok. 30 minut, dyplom z kodem.

- Gra: https://maciej-janowicz.github.io/volt-wyklad6/
- Panel prowadzącego (sprawdzanie kodów): https://maciej-janowicz.github.io/volt-wyklad6/#nauczyciel

Jeden plik `index.html`, bez serwera i bez zbierania danych; postęp zapisuje się w przeglądarce gracza.

## Publikacja w GitHub Pages
1. Utworzyć publiczne repozytorium `volt-wyklad6`.
2. *Add file → Upload files*: wgrać `index.html` i `README.md`, zatwierdzić (*Commit changes*).
3. *Settings → Pages → Build and deployment*: *Deploy from a branch*, gałąź `main`, katalog `/ (root)`, *Save*.
4. Po 1–2 minutach gra działa pod adresem powyżej.
